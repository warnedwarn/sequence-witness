SequenceWitness

Validator-backed verification that a claimed sequence is supported by two public records.

StudioNet contract

0x50CA0f6831d9b9f15740e7cA922E6b09ef6b5896

Open contract in GenLayer Explorer

Workflow

  1. Register ordered steps and two distinct HTTPS records.
  2. Verify the sequence using validator consensus.
  3. Read the resulting verdict, evidence indexes, and digests.

Use it

In Explorer call register_sequence, then verify_sequence; use get_sequence to inspect the stored result.
